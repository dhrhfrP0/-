# 스위치등 — 조명 스위치 안내판 만들기

교실·강당·사무실처럼 넓은 공간에서는 스위치를 하나씩 눌러봐야 어느 등이 켜지는지 알 수 있습니다.
이 사이트는 **어느 스위치의 어느 버튼이 어느 등을 켜는지** 한 장으로 정리해 인쇄할 수 있게 해 줍니다.

빌드 도구나 서버가 필요 없는 정적 사이트입니다. `index.html`을 열면 바로 동작하고,
그대로 GitHub Pages 같은 정적 호스팅에 올릴 수 있습니다.

## 쓰는 순서

1. **양식 만들기** 를 누릅니다.
2. **방 평면도가 있습니다 / 없습니다** 중에 고릅니다.
   - *있습니다* — 평면도 이미지를 배경으로 깔고 그 위에 등을 얹습니다. 이미지 비율에 맞춰 도면 비율이 자동으로 잡힙니다.
   - *없습니다* — 사전 양식(일반 교실, 강당, 복도 …)에서 가까운 모양을 고르면 방 비율·등 배치·스위치가 한 번에 채워집니다.
3. 방과 등을 다듬습니다. 방을 클릭하면 파워포인트처럼 여덟 개의 점이 나타납니다.
   점을 끌면 크기가, 안쪽을 끌면 위치가 바뀝니다(Shift를 누르면 비율 유지).
   등 크기는 방을 늘려도 그대로입니다.
4. **스위치 추가** 로 스위치판을 만들고 버튼 개수(○구)를 정합니다.
5. 패널에서 버튼을 누른 뒤, 그 버튼이 켜는 **등을 도면에서 클릭**해 연결합니다. 다시 클릭하면 해제됩니다.
   버튼 색은 처음에 회색이며, 개수 옆의 네모를 눌러 팔레트에서 고릅니다.
6. **인쇄 / PDF** 로 A4 한 장을 뽑습니다.

`작업 저장` 은 그림 파일이 아니라 나중에 다시 고치기 위한 작업 파일(`.json`)입니다.
인쇄물은 `인쇄 / PDF` 로 따로 뽑습니다.

## 만들어지는 안내판

**화면에서 편집하는 것이 곧 인쇄되는 A4 세로 한 장입니다.** 위에서부터 제목 · 방 · 스위치 칸으로
나뉘고, 덧붙는 머리말이나 꼬리말이 없습니다.

- 방 도면 위의 각 등에 **그 등을 켜는 버튼 번호**가 찍힙니다.
- 아래 스위치 칸에 스위치판 그림과 버튼별 설명이 나란히 놓입니다.

스위치가 둘 이상이면 버튼 이름이 `가1`, `나2`처럼 앞글자와 함께 표시됩니다.
색만으로 구분하면 흑백 프린터에서 무용지물이 되기 때문에, **글자만 봐도 구분되도록** 만들었습니다.

## 기능

| | |
|---|---|
| 사전 양식 | 일반 교실 · 특별실 · 강당 · 사무실 · 복도 |
| 등 모양 | 가로 형광등 · 세로 형광등 · 사각 등 · 원형 등 |
| 등 크기 | 소 · 중 · 대 (툴바에서 고른 모양을 한 번 더 누르면 나옵니다) |
| 줄 맞추기 | 끌 때 다른 등·스위치판과 줄이 맞으면 붙고 분홍 안내선이 나옵니다 |
| 배치 | 클릭해 추가, 드래그로 이동(줄 맞춤), 격자 자동 배치, 지우개 |
| 스위치 | 여러 개 · 버튼(구) 1~8개 · 버튼마다 설명 |
| 버튼 색 | 기본 회색 · 팔레트 12색 · 직접 고르기 |
| 스위치 생김새 | 매입형 세로 배열 · 매입형 가로 배열 · 터치 유리 · 노출형 원형 (한국에서 쓰는 것만) |
| 방 | 여덟 점으로 크기 조절, 끌어서 이동 |
| 종이 | A4 세로 고정 (A3·A5에도 그대로 맞음) |
| 스위치 개수 | 한 장에 넷까지 |
| 3로 스위치 | 한 등에 여러 버튼을 연결하면 `가1·나1` 처럼 함께 표시 |
| 벽 이름표 | 칠판 · 창문 · 출입문 등 네 방향 |
| 저장 | 브라우저에 자동 저장, `.json` 파일로 내보내기·불러오기 |
| 되돌리기 | Ctrl+Z |

단축키: `V` 선택 · `L` 등 추가 · `E` 지우개 · `Delete` 선택한 등 삭제 · `Esc` 선택 해제

## 올리기

정적 파일 세 개가 전부라 빌드가 필요 없습니다.

**GitHub Pages**

1. 저장소가 비공개면 먼저 공개로 바꿉니다.
   무료 계정은 비공개 저장소에서 Pages를 쓸 수 없습니다 (Settings → Danger Zone → Change visibility).
2. **Settings → Pages → Source: `Deploy from a branch`** 에서 `main` 과 `/ (root)` 를 고르고 Save.
3. 2~3분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

저장소에 있는 빈 `.nojekyll` 파일은 Pages가 Jekyll로 한 번 더 가공하지 않게 막아 줍니다.

**파일 하나로 묶기** — 메일로 보내거나 USB에 담아 인터넷 없이 쓰려면:

```
python3 build-single.py dist/index.html
```

`dist/index.html` 하나만 있으면 어디서든 그대로 열립니다.

## 스위치 생김새

한국 매입 스위치는 버튼이 **위아래로 쌓이고**, 4구가 넘으면 두 줄(2연장)이 됩니다.
버튼 오른쪽의 짧은 빗금도 실제 제품에 있는 표시입니다. 기본값이 이 형태입니다.

인쇄 범례의 스위치판도 도면과 같은 그림으로 나옵니다.
벽에서 스위치를 찾을 때 종이의 그림과 실물이 같아야 도움이 되기 때문입니다.

## 광고 자리

넓은 화면(1280px 이상)에서 본문 양옆에 세로 여백이 열립니다.
`index.html` 의 `#ad-left` / `#ad-right` 안에 AdSense 코드를 넣으면 됩니다.

```html
<aside class="ad-rail" id="ad-left" aria-hidden="true">
  <!-- 여기에 AdSense 코드 -->
</aside>
```

폭은 1280px 이상에서 176px, 1660px 이상에서 320px입니다.
좁은 화면에서는 자리가 접혀 본문이 화면을 다 씁니다.

## 파일

```
index.html        화면 구조
style.css         화면 + 인쇄 스타일
app.js            상태, 도면 SVG 그리기, 조작, 인쇄 시트 생성
build-single.py   위 셋을 파일 하나로 묶는 스크립트
```

외부 라이브러리를 쓰지 않습니다. 도면은 SVG로 그려 인쇄해도 깨지지 않고,
인쇄는 브라우저의 인쇄 기능(`@page` + 인쇄 전용 스타일)을 그대로 씁니다.
평면도 이미지와 작업 내용은 브라우저 안에만 저장되며 서버로 전송되지 않습니다.
